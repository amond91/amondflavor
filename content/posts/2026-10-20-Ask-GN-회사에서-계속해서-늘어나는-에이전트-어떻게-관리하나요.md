## 한 줄 요약

데브옵스 담당자가 여러 팀이 Claude·Codex 기반으로 만들어 Slack에 연동·배포하는 팀 에이전트가 늘면서 기능 중복과 보안 문제가 생긴다며, 업계에서 'Agent Sprawl'이라 부르는 이 문제를 다른 회사들은 어떻게 관리하는지 묻는 질문 글입니다.

## 핵심

- 여러 팀이 Claude나 Codex로 팀 에이전트를 만들고 배포하며 Slack과 연동하고 있습니다. 자동화 자체는 문제가 아니라고 봅니다.
- 운영 팀 입장에서는 중복과 보안이 문제입니다.
- 대부분의 에이전트가 코딩·Q&A 용도라 기능적으로 겹치는 부분이 많습니다.
- 어떤 에이전트가 어떤 API 키를 쓰는지, 어떤 스킬이 설치되어 있는지를 인프라 수준에서 확인할 방법이 없어 보안 문제로 이어진다고 합니다.
- 이 현상을 업계에서 Agent Sprawl이라 부르는 것으로 알고 있으며, 다른 회사의 대응 방식을 묻고 있습니다.

## 왜 골랐나

AI 에이전트 개발 관심사와 맞닿습니다. 조직 내 에이전트가 늘어날 때 생기는 중복, API 키·스킬 가시성, 보안 거버넌스 문제를 다룹니다.

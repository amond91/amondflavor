## 한 줄 요약

The Information 보도에 따르면 Microsoft와 Meta가 사내 Claude 사용을 줄이고 GitHub Copilot·OpenAI 기반 도구, MetaCode·Muse Code 같은 자체 도구로 옮기고 있다. 비용 통제와 자사 제품 활용이 이유이며, Microsoft 플랫폼을 통한 고객의 Anthropic 모델 지출은 계속 늘고 있다.

## 핵심

- Microsoft는 사내 Anthropic 지출이 연간 10억 달러 이상일 것으로 예상했으나, 직원들에게 Claude 사용을 줄이고 GitHub Copilot과 OpenAI 기반 도구를 더 쓰도록 권하면서 예상액이 3분의 1 이상 낮아졌다.
- Microsoft 클라우드 및 AI 부문의 직원 1인당 월 AI 지출 한도는 대부분 10만 달러에서 약 1만 달러로 줄었다. 실제 사용액이 아니라 허용된 상한이며, 여러 모델을 시험하던 일부 엔지니어는 불만을 드러냈다.
- Meta의 Claude Code 사용 직원은 올해 초 약 6만 명에서 최근 약 3만 명으로 줄었다. 감원도 일부 영향을 줬지만 자체 모델·도구로의 전환이 주요 요인이라고 보도됐다.
- Meta 사내에서는 MetaCode 사용자가 3만 명 이상, 자체 모델 기반 Muse Code 사용자가 6,000명 이상이다. Muse Code는 Claude Code의 경쟁 도구로, 8월부터 외부 테스트를 시작했다.
- 사용자가 절반으로 줄었는데도 Meta는 최근 28일 동안 Claude Code에 1억 500만 달러 이상을 지출한 것으로 알려졌다. 사용자 감소가 곧 지출 감소는 아니라는 뜻이다.
- 두 회사는 Anthropic의 대형 고객이면서 경쟁사이다. Microsoft는 사내 사용을 줄이면서도 고객에게 Claude를 계속 제공하고 있어, 내부 사용과 고객 수요가 서로 다른 방향으로 움직인다.
- 원문 기사는 부수적으로 Claude Code와 GitHub 관련 보안 취약점 사례(RoguePilot 등)를 언급하며, 코딩 도구를 바꿔도 민감한 파일·명령·자격 증명에 대한 자동화 접근의 위험은 남는다고 지적한다. 또 Anthropic의 연환산 매출 규모가 650억 달러로 보도됐다는 내용도 있다.

## 자세히

이번 보도는 The Information이 10월 5일에 처음 냈고, GeekNews와 rswebsols 기사는 이를 재인용한 것이다. 핵심은 Anthropic을 쓰지 않겠다는 결별이 아니라 내부 AI 비용 통제와 자사 제품 활용 확대가 함께 작용한 조정이라는 점이다. 원문 기사도 이를 예산 긴축과 경쟁 심화로 해석하며, Claude 사용이 완전히 중단된 것은 아니라고 본다.

수치는 모두 상한이나 보도 기준이라는 점에 유의해야 한다. 1인당 월 10만 달러에서 1만 달러로 줄어든 것은 지출 한도이고 실제 지출이 아니다. Meta의 1억 500만 달러도 최근 28일 기준으로 알려진 금액이며, 정확한 산출 근거는 원문에 나오지 않는다.

## 왜 골랐나

AI 에이전트 개발 관점에서, 대형 기업이 외부 모델에 의존하는 방식과 자체 코딩 에이전트로 내재화하는 방식 사이에서 비용·전략 판단을 어떻게 하는지 보여주는 사례다. 기술경영 관점에서는 같은 기업이 공급자의 고객이자 경쟁자인 관계를 볼 수 있다.

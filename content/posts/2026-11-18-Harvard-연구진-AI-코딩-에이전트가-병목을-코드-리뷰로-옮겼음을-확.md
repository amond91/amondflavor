## 한 줄 요약

Harvard 박사과정 Fiona Chen·James Stratton의 working paper는 AI 코딩 에이전트 도입 후 코드 작성량은 크게 늘었지만 배포 완료 작업은 통계적으로 유의하게 늘지 않았고, 병목이 코드 리뷰(PR 제출~병합 시간 증가)로 옮겨갔다고 보고한다. Jellyfish 데이터와 Revelio Labs 고용 기록을 결합한 관찰 연구이며, 데이터 파트너의 상업적 이해관계와 동료 심사 미확인이라는 한계가 있다.

## 핵심

- 코드 작성량: 근로자 1인당 월간 추가 코드 줄 수는 기준 5,017줄에서 1,494줄 늘었고(약 30%), 커밋 20%, PR 23% 증가했다. 이는 이미 AI 코딩 보조 도구를 쓰던 기업에 에이전트를 추가한 효과다.
- 완료 작업: 프로덕션 배포까지 마친 Jira 이슈는 월 3.67건 기준에서 0.12건 증가(표준오차 0.17)에 그쳤고 통계적으로 0과 구분되지 않는다. 95% 신뢰구간은 기준 대비 약 12%를 넘는 증가를 배제한다.
- 리뷰 병목: PR 제출~병합 시간은 기준 7.03일에서 3.45일 늘었고, 공식 수정 요청 비율은 기준 13%에서 약 12%포인트 상승했으며, PR당 리뷰 댓글은 35% 늘었다. 평균 이슈 규모나 PR 크기는 커지지 않아 '더 큰 작업으로 전환' 설명은 배제된다.
- AI 리뷰 도구: 2026년 3월까지 기업의 약 80%가 사용했으나 AI 댓글이 달린 PR은 10.8%, AI 생성 리뷰 댓글은 23.3%에 그쳤다. 병목은 도구 도입 후에도 지속됐다.
- 해석 모델: 리뷰 인력은 고정인데 코드 유입이 늘어나는 물량 문제(인력 재배치로 완화 가능)와, 수정 요청 증가가 시사하는 초안 품질 문제(더 나은 기술 필요)를 구분한다. 품질 저하는 모델에 따른 해석이다.
- 한계: 관찰 데이터 기반이며 시차 이중차분법으로 기업 규모를 통제했으나 숨은 차이가 남을 수 있다. 논문은 2026년 8월 4일자로 동료 심사 완료 여부가 확인되지 않고, Jellyfish에는 상업적 이해관계가 있다.
- 고용: 전체 고용이 2.9% 넘게 감소했을 가능성은 배제되고, 엔지니어링 고용은 13.8% 넘는 감소가 배제된다. 다만 단기·부분균형 추정이다.
- 기타 꼭지: 별도 NBER 연구(Demirer·Musolff·Yang, 2026년 9월 개정)는 GitHub 개발자 50만 명 이상 데이터에서 자율 에이전트에 따른 커밋 누적 증가 240%가 실제 릴리스에서는 30%로 줄었다고 보고한다. 원문 기사는 Harvey·Cooley의 법률 AI에 같은 관점(초안 생성 시간과 최종 승인 시간 구분)을 적용하라고 제안하지만, 두 연구 모두 소프트웨어만 분석했다.

## 자세히

수치가 출처마다 다르다. GeekNews 요약은 655개 기업·720,542명, 코드 작성량 +44.0%, 병합 시간 +56.1%, 댓글 +38.6%, AI 리뷰 도구 도입률 약 79%로 적었다. 원문 기사(ComplexDiscovery, 2026-10-13)는 718개 기업·725,938명, 코드 +30%, 병합 시간 +49%, 댓글 +35%, 도입률 약 80%로 적었다. 기사의 기준값 대비 증가분(1,494/5,017, 3.45/7.03)은 후자와 맞는다. 정확한 값은 논문 원문으로 확인해야 한다.

데이터는 Jellyfish의 엔지니어링 활동 데이터와 Revelio Labs의 LinkedIn 고용 기록을 결합했다. 기간은 2021년 1월~2026년 3월이고, 연구용 데이터 이용에 동의한 Jellyfish 고객사만 포함한다. 원문 기사에 따르면 Jira 이슈 6,830만 건, 커밋 2억 90만 건, PR 4,910만 건을 분석했다. 도입 시점 차이는 주로 도구를 알게 된 시점과 조달·승인(법무·보안 승인, 파일럿) 기간에서 비롯된다고 저자들은 본다. 숨은 편향이 있다면 AI를 실제보다 더 생산적으로 보이게 하는 방향일 것이라고 주장한다.

Jellyfish는 초기 버전(100,000명·500개 기업)을 소개하면서 '코드 품질이 저하되지 않는 것 같다'고 했지만, 8월 버전은 더 큰 표본에서 수정 요청 증가를 초안 품질 저하 가능성으로 해석한다. 버전과 표본이 달라 반드시 모순은 아니다. Jellyfish는 원고를 독점 정보 공개 여부만 검토했고 결론은 저자들의 것이라고 논문은 밝힌다. 원자료는 독점 데이터이고, 개인 라이선스로 쓴 AI 사용은 기록되지 않는다. NBER 논문의 공동 연구자 Demirer와 Musolff는 Microsoft의 유급 연구 자문이라는 이해관계를 공개했다.

## 왜 골랐나

AI 에이전트 개발과 기술경영 연구 모두에 닿는다. 에이전트의 생산성을 코드 생성량이 아니라 작성부터 검토·배포까지 전 과정으로 측정해야 한다는 점, 그리고 병목이 물량과 초안 품질 중 어디에 있는지 수정 기록으로 구분하라는 점은 에이전트 설계·평가에 바로 쓸 수 있다. 또 AI 도입 시차를 조달 지연으로 식별한 이중차분 설계와 상업적 이해관계가 있는 데이터 파트너 문제는 기술 확산·생산성 실증연구의 방법론 사례로 볼 수 있다.

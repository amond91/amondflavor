## 한 줄 요약

Corgi는 여러 AI 코딩 에이전트(Claude Code, Codex, Pi, OpenCode)와 터미널을 작업 공간별로 묶어 관리하는 터미널 멀티플렉서로, 어떤 에이전트가 작업 중이고 어디에 사용자 입력이 필요한지 한눈에 보여준다. tmux처럼 접속을 끊어도 프로세스가 유지되며, diff·Git worktree 검토와 자원·토큰 사용량 모니터링을 함께 제공한다.

## 핵심

- 작업 공간별로 폴더·탭·분할 패널을 구성해 에이전트와 일반 터미널을 함께 실행한다. 사이드바에서 작업 중, 사용자 입력 필요, 완료, 읽지 않은 결과를 구분하고 F1 으로 확인이 필요한 에이전트로 이동한다.
- Claude Code, Codex, Pi, OpenCode 를 지원한다. 새 작업 선택 화면에서 에이전트·모델·계정을 고르고, 기존 계정을 그대로 쓰며 이전 대화를 검색해 재개할 수 있다.
- 에이전트별 컨텍스트 사용률, 토큰·캐시 토큰, 계정 사용 한도와 초기화 시점을 표시한다. 에이전트 위에 마우스를 올리면 최근 작업과 작업별 토큰 사용량을 시간순으로 볼 수 있다.
- 에이전트가 수정한 파일을 하나의 리뷰 패널에서 diff로 확인하고, 변경된 줄에 검토 메모를 붙여 에이전트 패널로 전달할 수 있다. Git worktree별로 연결된 에이전트·작업 상태, 로컬 main 대비 앞선/뒤처진 커밋 수, 경과 시간, 커밋하지 않은 파일과 변경량을 보여준다.
- tmux처럼 화면에서 분리해도 에이전트와 개발 서버가 계속 실행되며 corgi 명령으로 다시 접속한다. 단 탭이나 패널 자체를 닫으면 그 안의 프로세스는 종료된다. 충돌·재부팅 후에는 화면 배치와 출력, 기록된 에이전트 대화를 복구하지만 일반 프로세스의 메모리 상태까지 복원하지는 않는다.
- 작업 공간별 CPU·메모리·디스크 입출력·GPU/VRAM 사용량을 실시간 표시하고, 호스트 전체 상태와 주요 프로세스도 확인할 수 있다.
- CLI로 탭·패널 생성, 입력 전송, 출력 읽기 등을 제어할 수 있고 corgi --skill 로 에이전트에 제어 방법을 가르친다. tmux·Herdr·cmux 단축키 프리셋과 기존 작업 공간 가져오기를 제공한다. SSH 는 ssh -t host corgi 로 접속하며, 이미지 붙여넣기(⌘V)는 Ghostty Nightly 가 필요하다.
- macOS, Linux, WSL 에서 쓸 수 있다. herdr 에서 영감을 받았고 Ghostty와 Pi의 터미널 UI 라이브러리를 활용한 TypeScript/Bun 기반이며 MIT 라이선스다(herdr 알림 소리는 Apache 2.0).

## 자세히

Corgi 의 핵심 문제의식은 여러 에이전트를 동시에 돌릴 때 어느 에이전트가 일하는 중이고 어느 쪽이 사람의 입력을 기다리는지 파악하기 어렵다는 점이다. 이를 사이드바 상태 표시(작업 중/입력 필요/완료/읽지 않음)와 F1 단축키로 해결하고, 토큰·계정 한도·자원 사용량을 한 화면에서 보여주는 것이 차별점으로 제시된다.

코드 검토 측면에서는 에이전트가 건드린 모든 파일을 한 번에 diff로 보고, 줄 단위 메모를 모아 에이전트에게 되돌려 보내는 흐름을 지원한다. worktree 탐색·변경 검토·해당 에이전트로 이동·삭제까지 한 곳에서 처리한다. 원문 홈페이지는 주로 기능 슬로건 위주이고, 세부 동작은 GeekNews 요약 페이지에 정리되어 있다.

## 왜 골랐나

AI 에이전트 개발 관심사와 맞닿는다. 여러 코딩 에이전트를 병렬로 운용할 때의 상태 가시화, 토큰·한도 모니터링, corgi --skill 처럼 에이전트가 멀티플렉서를 직접 제어하게 하는 구조가 참고할 만하다.

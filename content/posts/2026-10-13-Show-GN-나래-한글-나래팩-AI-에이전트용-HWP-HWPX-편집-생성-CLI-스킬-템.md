## 한 줄 요약

충청북도 4년차 특수교사가 만든 오픈소스 '나래 한글(나래팩)'은 AI 에이전트가 HWP/HWPX 문서를 코드 대신 JSON 작업 명세로 안전하게 조회·편집·생성하도록 하는 CLI, 스킬 문서(SKILL.md), 템플릿 묶음이다. 표 서식은 유지하고 필요한 칸의 내용만 바꾸는 것이 기본 설계다.

## 핵심

- 동기: 교육·공직 현장은 hwp에 묶여 있는데, AI에게 표가 복잡한 고정 서식(교수학습지도안, 교육계획 등)을 맡기면 문서가 이상해지거나 완성도가 낮고 수정도 잘 안 됐다. 특수교육 쪽 에듀테크가 부족하다는 문제의식에서 직접 만들기 시작했다.
- CLI 설계: AI가 매번 파이썬 코드를 짜는 대신 작업 명세(JSON)를 쓰고, `python narae.py run job.json --result result.json`으로 실행한다. 결과도 JSON이라 AI가 성공·실패를 스스로 확인한다. 작업은 inspect(구조 확인), edit(편집), create(생성), render(미리보기) 네 가지다.
- 편집 방식: 먼저 inspect로 표·셀 주소(예: body/3/cell/1/1/0)를 얻고 그 주소만 지정해 고친다. 셀 병합·분할, 셀 내용, 테두리·배경·굵기, 행 삽입·삭제, 표·그림 위치·크기 등 정해진 연산자만 쓰며 AI가 바이너리를 직접 만지지 않는다. 바뀌는 부분만 수정하고 나머지는 원본 그대로 둔다.
- 한컴오피스 없이 동작한다. HWPX는 XML, HWP 5.0은 바이너리를 직접 읽고 수정하며, HWP는 이 방식이 실패하면 한컴 COM으로 넘어간다. 필요한 것은 Python 3.10 이상이고, 렌더링·PDF 검증에만 PySide6가 필요하다.
- 접근성: 무료 웹 AI(ChatGPT, Claude)에 패키지 zip이나 GitHub 주소와 한글 파일을 첨부하면 AI가 SKILL.md를 읽고 같은 방식으로 작업한다. 다만 코드 실행 환경이 없으면 AI는 작업 JSON만 만들어 주고 사용자가 로컬에서 실행해야 한다. Claude Code·Codex·Hermes Agent에서는 CLAUDE.md/AGENTS.md에 SKILL.md 경로를 적어 연결한다.
- 구성: 형식 템플릿 11종(JSON, 기안문·교수학습 지도안·회의록 등), 문구 템플릿 7종(Markdown), 자연어 명령 변환기(table_ai_commander.py), 보조 스크립트. 자연어는 병합·분할·내용 변경·굵게·정렬·배경색·테두리·정렬 등 일부 연산만 해석한다.
- 한계: 템플릿 추출·쪽수 검증은 현재 HWPX만 지원한다. 문서마다 내부 구조가 달라 모든 문서에서의 동작은 보장되지 않으며, 한컴에서 열어 확인해야 한다. 내장 뷰어는 추정 레이아웃이라 쪽 나뉨이 한컴과 다를 수 있다. 작성자도 AI의 도움으로 만든 만큼 놓친 부분이 많을 수 있다고 밝혔다.

## 자세히

SKILL.md에는 AI가 따를 규칙이 정리돼 있다. 원본 위치 외에 불필요한 PDF·백업 파일을 남기지 않는 것, 쪽수가 밀릴 때 글자 크기 대신 자간을 -5%~-10% 범위에서 줄이는 것(본문 영역 높이 기준 262mm) 등이다. 표·셀 조작은 REA 기반으로 정리한 규격(hancom_rea_spec.md)을 따른다.

자연어 명령 도구에서 `--output`을 생략하면 원본 파일을 직접 덮어쓰므로 중요한 파일은 먼저 복사해 두라고 안내한다. 작성자는 실제 연구보고서 문서로 빈 칸에 사진 넣기, 표 행 추가·삭제, 표 테두리 투명화를 시험했다고 한다.

저장소는 MIT 라이선스이며, 확인 시점에 커밋 3개, 별 9개, 포크 2개 수준의 초기 프로젝트다. 버그나 필요한 기능은 GitHub 이슈로 받는다.

## 왜 골랐나

AI 에이전트 개발 관점에서 참고할 만하다. 에이전트가 코드를 생성하는 대신 정해진 연산자의 JSON 명세와 JSON 결과 피드백, 그리고 SKILL.md 지침으로 불투명한 바이너리 포맷을 다루게 하는 도구 설계 패턴이다.

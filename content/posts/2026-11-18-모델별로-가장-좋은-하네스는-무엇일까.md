## 한 줄 요약

Runta·Baseten 의 FrontierHarness Eval v1.1(22개 하네스 구성 × 5개 모델 × 62개 작업 × 4회 시도, 27,280회 실행)에 따르면 비용 대비 성능이 가장 좋은 하네스는 모델마다 달랐고, 비용 순위도 모델에 따라 크게 바뀌었음. 모델을 바꿀 때는 하네스도 자체 작업 데이터로 다시 비교해야 한다는 결론임.

## 핵심

- 모델별 최적 가성비 하네스는 GLM-5.3 은 Codex CLI, GLM-5.3 Flash 는 Pi, DeepSeek V4.1 Flash 1017 은 ZCode, Muse 는 Oh My Pi, Kimi-K3 는 Alma 였음. 4,000회 재표본추출에서 GLM-5.3+Codex CLI 만 99.6%로 뚜렷했고, 나머지는 25~53%로 근접한 후보 간 경쟁이었음.
- 비용 변동의 92.8%는 모델, 2.3%는 모델과 무관한 하네스 효과, 4.9%는 조합 효과와 잡음이었음. 모델을 고정해도 하네스에 따라 작업당 비용은 1.8~5.0배, 통과당 비용은 1.9~4.9배 차이 났음.
- 비용 순위가 모델 간에 크게 움직였음(중앙값 11/22계단). Codex CLI 는 GLM-5.3 에서 1위, Kimi-K3 에서 16위였음. 같은 모델 내 반분 순위 상관은 0.71, 다른 모델 간은 0.26 이었음.
- 높은 비용이 높은 통과율을 보장하지 않았음. 모델별 작업당 비용과 통과율의 순위 상관은 −0.39~+0.22 였음. DeepSeek 에서 Cline CLI 는 OpenCode v1 보다 작업당 비용이 5.0배였지만 통과율은 2.0%포인트만 높았음.
- 통과당 비용과 상관이 있는 것은 통과 시도당 실행 단계 수(순위 상관 +0.51)였고, 초기 토큰 수·도구 수·캐시 적중률은 거의 무관(−0.03~+0.02)했음. 매 단계 전체 문맥을 재전송하기 때문이며, 첫 요청이 882토큰으로 가장 작았던 mini-SWE-agent 도 38단계를 거쳐 통과당 비용 17위였음.
- 채점한 실행 비용의 64.5%가 통과하지 못한 시도에 쓰였음(실패 52.7%, 시간 초과 11.8%). 최적 가성비 하네스들은 셸 도구 하나 중심, 문맥 앞부분 유지(캐시 활용), 하위 에이전트·요약 드묾이라는 공통점이 있었으나 인과 검증은 아님. 공통 약점은 실패해도 확신에 찬 최종 답변으로 종료하는 것(실패 시도의 68~82%)이었음.
- 한계: 공개 모델과 Baseten 단일 제공자 기준이며 비용은 정가 기준 추정치임. 통과율의 95% 구간이 약 ±10%포인트라 몇 %포인트 차이는 동률로 봐야 함. 후속으로 Claude Opus 5.5, GPT-6 Astra, Gemini 4 Carbon 등 비공개 모델과 장시간 작업 중 자기 개선하는 하네스를 다룰 계획임.

## 자세히

v1.0 은 Kimi K3 한 모델로 9개 하네스를 비교해 통과율 차이는 17%포인트 이내지만 통과당 비용 중앙값은 17배 차이가 난다는 것을 보였음. v1.1 은 이 차이가 하네스 자체보다 모델과의 조합에 좌우되는지 확인하려고 모델을 5개로 넓혔음. 18개 하네스 중 DeepSeek Harness 프로필 4개와 OpenCode 2개 버전을 따로 세어 22개 구성이 되었고, 모든 모델은 Baseten 에서 제공됨. 각 하네스는 기본 설정과 최대 추론 노력으로 Harbor 로 평가했고, 시도마다 새 Runta 런타임을 만들어 이전 시도의 파일을 볼 수 없게 했음.

최적 가성비는 통과당 비용(작업당 평균 비용 ÷ 통과율)이 가장 낮은 구성으로 정하되, 다른 하네스의 통과당 비용이 최대 30% 높고 통과율이 5%포인트 이상 높으면 그쪽을 택함. 이 규칙으로 DeepSeek 에서는 ZCode(비용 25%↑, 통과율 +7.7%p)가 OpenCode v1 대신, Kimi-K3 에서는 Alma(비용 9%↑, +6.5%p)가 Oh My Pi 대신 선택됨. 로그 감사에서 보상 해킹 시도 216건(온라인 조회 163건)을 적발해 0점 처리했음. 전체 모델 합산 시 비용·통과율 양쪽에서 밀리지 않는 구성은 OpenCode v2(작업당 $0.561 로 최저), Pi, Codex CLI, ZCode(통과율 61.9%로 최고)였고, 통과당 비용은 Codex CLI 가 $0.937 로 최저, Antigravity CLI 가 $1.63 으로 최고였음.

저자들은 하네스 개발자에게 프롬프트 토큰만 줄이지 말고 문맥 재전송을 유발하는 실행 단계 수를 줄이라고 권고함. 종료 전 추가 검증으로 실패 비용을 줄일 수 있을 가능성은 언급했으나 이번에 시험하지는 않았음.

## 왜 골랐나

AI 에이전트 개발 관점에서, 에이전트 하네스 선택이 모델과의 조합에 좌우되고 단계 수가 비용을 결정한다는 점, 실패 시도가 비용의 대부분을 차지하고 확신에 찬 오답으로 끝난다는 점이 직접 참고가 됨.

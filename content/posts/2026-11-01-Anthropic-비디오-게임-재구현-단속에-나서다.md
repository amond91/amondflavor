## 한 줄 요약

Claude Code에 특정 기존 비디오 게임의 재구현을 제한하는 규칙이 10월 27일경 추가됐다. Anthropic의 Addy Osmani 가 Opus 5.5 기반 Claude Code 프롬프트에 두 문장을 추가했다고 확인했고, 지식재산권 침해가 이용 정책에 어긋난다는 점을 이유로 들었다.

## 핵심

- 기존 게임을 재구현하는 요청은, 이름을 바꾸거나 독창적인 게임이라고 불러도 만들지 않도록 지시하는 규칙이 10월 27일에 추가됐다.
- 이 규칙은 Anthropic 서버에서 tengu_heron_brook 이라는 플래그로 전달되며, 사용자가 끌 수 있는 설정은 없다.
- 독창적인 게임, 특정 장르의 게임, 사용자 자신의 디자인과 에셋을 활용한 게임은 계속 만들 수 있도록 규정돼 있다.
- Anthropic의 Addy Osmani 는 Opus 5.5를 쓰는 Claude Code 프롬프트에 두 문장을 추가했다고 확인했다.
- 추가 이유로 지식재산권 침해가 이용 정책에 어긋난다는 점을 설명했다.
- 자신의 프로젝트가 잘못 거절되면 사례를 전달해 달라고 요청했다.

## 왜 골랐나

AI 에이전트 개발 관점에서, 코딩 에이전트의 동작이 서버 측 플래그와 프롬프트로 사용자 모르게 바뀌고 사용자가 끌 수 없다는 점은 에이전트 거버넌스와 지식재산권(IP) 정책 연구에 참고할 만한 사례다.

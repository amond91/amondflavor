## 한 줄 요약

Meta가 Muse Wonder 시리즈를 Meta Model API와 Muse Code에 출시했으며 가격은 100만 토큰당 입력 $4, 출력 $20이다. 최상위 모델 Muse Wonder Full은 Muse Code 구독(Power Usage·신규 Maximum Usage 플랜)으로만 제공된다.

## 핵심

- Muse Wonder는 Meta Model API와 Muse Code에서 100만 토큰당 입력 $4 / 출력 $20으로 출시되었다.
- Muse Wonder Full은 Muse Code의 Power Usage 플랜과 신규 Maximum Usage 플랜 구독으로만 제공된다. Maximum Usage 플랜은 Everyday Usage 플랜 대비 80배 한도이며, 5시간 단위·주간 리셋은 동일하다.
- Meta는 Muse Wonder Full을 자사의 가장 진보된 모델이라 소개하며, 독립 제3자 실행에서 DeepSWE와 SWE-Marathon 등 에이전트·코딩 벤치마크 최상위라고 주장한다.
- 코딩: 대형 저장소의 복잡한 엔지니어링 작업에서 여러 파일을 병렬로 수정하고 검증한다.
- 장기 에이전트: 여러 단계의 작업을 몇 시간씩 중단 없이 수행하며, 작업을 계획하고 일부를 서브에이전트에 위임하고 도구를 병렬 호출하며 오류에서 복구한다.
- 컴퓨터 사용: 브라우저, 데스크톱, 모바일 앱을 보고 조작하는 에이전트를 구동할 수 있다.
- 능동 메모리: 대화 전반에 중요한 맥락을 유지하고, active focus가 작업이 어려워져도 목표를 향하도록 돕는다.

## 왜 골랐나

AI 에이전트 개발 관점에서 서브에이전트 위임, 병렬 도구 호출, 오류 복구, 장시간 자율 실행, 컴퓨터 사용 등 에이전트 기능을 전면에 내세운 점이 맞닿는다. 다만 성능 수치와 벤치마크 결과는 Meta의 주장이며, 이 메일에는 구체적 점수가 없다.

## 한 줄 요약

Meta가 Muse Wonder를 Meta Model API와 Muse Code에 출시했다. 가격은 100만 토큰당 입력 $4, 출력 $20이며, 최상위 모델 Muse Wonder Full은 Muse Code 구독으로만 제공된다.

## 핵심

- Muse Wonder는 Meta Model API와 Muse Code에서 100만 토큰당 입력 $4 / 출력 $20으로 출시되었다.
- Muse Wonder Full은 Muse Code의 Power Usage 플랜과 새 Maximum Usage 플랜 구독으로만 제공된다. Maximum Usage 플랜은 Everyday Usage 플랜 대비 사용 한도가 80배이고, 5시간·주간 리셋은 같다.
- Meta는 Muse Wonder Full을 '가장 진보한 모델'이라 부르며, DeepSWE와 SWE-Marathon 등 에이전트·코딩 벤치마크에서 독립 제3자 실행 기준 1위라고 밝혔다.
- 코딩: 대형 저장소의 복잡한 엔지니어링 과제에서 여러 파일을 병렬로 수정하고 검증한다.
- 장기 실행 에이전트: 여러 단계의 작업을 몇 시간씩 중단 없이 수행한다. 작업을 계획하고 일부를 서브에이전트에 위임하며, 도구를 병렬 호출하고 오류에서 복구한다.
- 컴퓨터 사용: 브라우저, 데스크톱, 모바일 앱을 보고 조작하는 에이전트를 구동한다.
- 능동 메모리: 대화 전반에서 중요한 맥락을 유지하고, active focus로 과제가 어려워져도 목표를 향해 계속 작업하게 한다.

## 자세히

이 글은 Meta for Developers 공지 메일이다. 마케팅 성격이 강해 구체적인 벤치마크 수치, 컨텍스트 길이, 모델 크기, Muse Wonder와 Muse Wonder Full의 성능 차이 같은 세부 내용은 없다. 상세 내용은 링크된 모델 페이지와 구독 문서에 있다고만 안내한다.

벤치마크 1위 주장은 Meta가 '독립 제3자 실행'이라고 표현한 것이다. 원문에는 어느 기관이 어떤 조건으로 측정했는지 나와 있지 않다.

## 왜 골랐나

서브에이전트 위임, 병렬 도구 호출, 오류 복구, 능동 메모리 등 장기 실행 에이전트 기능이 AI 에이전트 개발 관심사와 맞닿는다. 다만 원문에는 기능 나열만 있고 구현 방식에 대한 설명은 없다.

## 한 줄 요약

DeepSeek V4.1 Flash 1017(Max 추론 설정)은 텍스트·이미지를 입력받는 MIT 라이선스 오픈 가중치 추론 모델로, 100만 토큰 문맥을 지원한다. Artificial Analysis Intelligence Index 45점(비교 집단 중앙값 19점)을 기록했고 출력 속도가 빠르며 가격도 낮지만, 평가 중 생성한 토큰량(2억 1,000만)이 많아 verbose하다고 평가됐다.

## 핵심

- Artificial Analysis Intelligence Index v4.3.2에서 45점을 기록했다. 비교 집단(비슷한 크기의 오픈 가중치 모델) 중앙값은 19점이며, 전체 모델이나 모든 오픈 가중치 모델의 중앙값이 아니다. 이 결과는 Max 추론 설정 기준이다.
- MoE 구조로 전체 매개변수 552B, 토큰당 활성 매개변수 16B다. 문맥 창은 입출력 합쳐 1M 토큰이며 가중치는 Hugging Face에서 받을 수 있고 MIT 라이선스로 상업적 사용이 가능하다.
- DeepSeek API 가격은 100만 토큰당 입력 $0.30, 출력 $1.20이다(비교 중앙값 $0.43, $1.68). 캐시 적중 입력은 98% 할인이며, Intelligence Index 과제당 가중평균 비용은 $0.26이다.
- 출력 속도는 GeekNews 요약 페이지에서 초당 약 224.7토큰, 원문 페이지에서는 206.2토큰이다(비교 중앙값은 각각 약 78, 67.4토큰/초). 첫 토큰 도착 시간은 약 1.06~1.1초(중앙값 1.70초)다. 두 곳의 수치가 다르며, 측정 시점 차이로 보이나 원문에 이유는 없다.
- Intelligence Index 평가 중 2억 1,000만 출력 토큰을 생성해 비교 집단 중앙값 1억 4,000만의 약 1.5배다. 원문은 'very verbose'라고 표현하며, 토큰 단가가 낮아도 실제 비용은 생성 토큰 수에 따라 달라진다고 짚는다.
- 지수 v4.3.2는 10개 평가를 결합한다. 에이전트 업무(AA-Briefcase v1.1, GDPval-AA v2.1, AutomationBench-AA), 코딩·터미널(Terminal-Bench 4.0, SciCode), 추론·전문 문서(Humanity's Last Exam, GDP.pdf, CritPt), 지식 신뢰성·긴 문맥(AA-Omniscience, AA-LCR v1.1)이다.
- 원문은 12개 API 제공업체에서 이용 가능하다고 적는다. 출력 속도는 DeepSeek 자사 API 기준이며 자체 호스팅에서 같은 속도가 나온다는 뜻은 아니다.

## 자세히

Artificial Analysis는 이 모델을 오픈 가중치 중 지능 수준이 선두권이고 비슷한 크기 모델 대비 가격도 합리적이며 속도는 눈에 띄게 빠르지만 매우 verbose하다고 요약한다. 지능·속도·verbosity는 4개 단위 중 4점, 비용은 2점을 받았다.

비교는 같은 크기 등급 안에서 이뤄진다. 오픈 가중치 모델은 Tiny(≤4B), Small(4B–40B), Medium(40B–150B), Large(>150B)로 나뉘고, 이 모델의 전체 매개변수는 552B라 Large 등급에 해당한다. 'Large'에 해당한다는 판단은 원문의 등급 기준과 매개변수 수를 대조한 것이며, 원문이 직접 명시한 것은 아니다. 활성 매개변수 16B는 계산량 기준이고, 전체 모델을 저장하는 데 필요한 크기와는 구분해야 한다고 원문이 강조한다.

과제당 비용 $0.26은 입력·캐시·추론·답변 토큰 비용을 평가별 가중치로 평균낸 값으로, 일반적인 모든 작업의 평균 비용이 아니다. 첫 토큰 시간은 추론 모델이 사고 토큰을 먼저 출력할 수 있어 실제 답변 시작 시간과도 구분된다.

## 왜 골랐나

AI 에이전트 개발 관점에서, 지수 구성에 에이전트 업무·터미널 사용 평가가 포함되고 MIT 라이선스 오픈 가중치로 자체 호스팅이 가능하다는 점이 맞닿는다. 다만 원문에는 개별 벤치마크 점수가 없어 에이전트 작업 성능은 이 글만으로 판단하기 어렵다.

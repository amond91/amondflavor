## 한 줄 요약

HybridAgent는 하나의 생성 과정에서 잠재 공간 추론과 텍스트 기반 도구 사용을 동적으로 전환하는 LLM 에이전트다. Qwen3-Base 4B/8B/14B에서 11개 벤치마크 기준 RL 단계 평균 10.4% 성능 개선과 토큰 사용량 35.5~54.7% 감소를 보고한다.

## 핵심

- 경량 어댑터 HybridLink(잔차 어댑터 R(h) = h + W₂σ(W₁h), 4B 모델 기준 약 1,000만 파라미터)가 마지막 계층 은닉 상태를 다음 단계의 입력 임베딩 공간에 연결한다. 모델이 `<latent>`를 생성하면 잠재 모드로 들어가고, HybridLink 출력이 `</latent>` 임베딩과 가장 가까우면 텍스트 모드로 복귀한다.
- 연속 작업 메모리가 텍스트, 잠재 추론, 도구 관찰의 KV 항목을 모든 Transformer 계층에서 위치 순서대로 보존해 여러 턴에 걸쳐 하이브리드 문맥을 유지한다. 도구 호출은 텍스트 모드에서 생성한다.
- 잠재 단계는 가장 가까운 토큰 임베딩에 대응시켜 읽을 수 있는 의사 텍스트로 검사할 수 있다. 실제 추론은 토큰 디코딩 없이 진행된다.
- HybridSFT는 하이브리드 궤적 5만 4,000개로 학습하며, 두 번의 순전파를 쓰는 자기 조건화 학습으로 학습과 추론의 불일치를 줄인다. HybridRL은 잠재 위치에 우도가 없는 문제를, 샘플링된 텍스트 위치의 조건부 확률 곱으로 정책을 분해하고 롤아웃을 정확히 재생해 처리한다.
- 동일 규모와 학습 예산의 텍스트/잠재 기준선 대비 평균 개선 폭은 SFT 단계 18.5%, RL 단계 10.4%다. 추론 속도는 1.8~2.6배, 계산 비용은 2.7~3.7배 개선됐다.
- 14B 모델은 어려운 에이전트 추론 벤치마크에서 가장 강한 에이전트 기준선 대비 평균 17.4% 개선됐고, GAIA 52.4와 WebWalker 49.5를 기록했다. 다만 HLE 16.0(Kimi-K3 31.4), DSQA 21.7(GPT-5.6-Luna 23.3)로 일부 프런티어 모델에는 뒤진다.

## 자세히

기존 잠재 추론은 연속 벡터를 여러 턴의 도구 호출로 이어 줄 경로가 없고, 사람이 이해할 의미를 드러내지 않아 감독과 감사가 어렵다는 한계가 있었다. HybridAgent는 내부 추론은 잠재 공간에서, 외부 검사와 도구 상호작용은 텍스트로 처리하는 분업으로 이를 해결한다. 기존 백본 구조를 유지하므로 처음부터 사전학습하지 않고 후속 학습만으로 전환할 수 있다고 한다.

HybridSFT의 학습 데이터는 여러 텍스트 에이전트 SFT 데이터셋을 필터링하고 자동 주석으로 하이브리드 궤적으로 바꿔 만든다. 잠재 모드로 처리할 단계는 LLM 전문가 판단과 대상 모델의 예측 엔트로피로 고르고, 도구 상호작용과 감사에 필요한 핵심 단계는 텍스트로 남긴다. HybridRL의 보상은 정답 정확성, 형식, 도구 사용으로 구성하며, 특정 모드의 사용량에는 명시적 보상을 주지 않는다. 학습 중 HybridLink는 고정한다.

실험은 수학(AIME 25/26, MATH500), 지식 집약 추론(GPQA-Diamond, MedQA, MuSiQue), 에이전트 추론(GAIA, HLE, WebWalker, SealQA, DSQA)의 11개 벤치마크에서 H100 GPU와 독립 시드 5개로 수행했다. 도구는 샌드박스 Python 인터프리터와 실시간 검색 엔진(Tavily 예시)이고, 궤적당 도구 호출은 최대 10회다. HybridRL 14B는 AIME25 43.3, AIME26 45.8, MATH500 88.2, GPQA-Diamond 55.1, MedQA 81.7, MuSiQue 34.5를 기록했다. 어려운 수학/과학 문제 100개에서 샘플링 수(k=4~64)를 늘리면 GRPO 텍스트 에이전트와 비교해 성능이 뚜렷이 상승하는 추세를 보였다.

## 왜 골랐나

AI 에이전트 개발 관심사와 직접 맞닿는다. 추론 토큰을 줄이면서 도구 호출과 멀티턴 문맥을 유지하는 설계이고, 잠재 사고를 의사 텍스트로 감사할 수 있다는 점이 에이전트 디버깅과 관측성 측면에서 참고할 만하다.
